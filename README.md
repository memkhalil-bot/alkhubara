# Experts Center Management System — MVP Demo

واجهة عربية RTL لإدارة مركز تعليمي، قابلة للنشر كـ Static Site على Vercel.

## التشغيل
افتح `index.html` محليًا، أو ارفع هذا المجلد إلى GitHub ثم Import في Vercel مع Framework Preset = Other.

## الوظائف
- لوحة مدير بإحصاءات مالية وتشغيلية ورسوم بيانية.
- إدارة الحصص والطلاب والمدرسين.
- الواجبات والأبحاث والمشاريع.
- تسجيل التحصيل والمصروفات والسلف.
- تقارير بالمدرس والطالب واليوم والأسبوع والشهر، وطباعة وتصدير CSV متوافق مع Excel.
- وضع سكرتارية تجريبي بدون أعمدة المبالغ.

## تحذير أمني مهم
هذه نسخة عرض فقط. تخزين البيانات في `localStorage`، واختيار الدور من القائمة ليس آلية صلاحيات أو تسجيل دخول حقيقي. **لا تدخل بيانات شخصية أو مالية حقيقية ولا تستخدمها في التشغيل الفعلي.** لا تعتمد على إخفاء عناصر الواجهة لحماية الأسعار. للإنتاج: Supabase Auth، سياسات RLS، API خادم يتحقق من الدور، جداول مالية محمية، تدقيق العمليات، ونسخ احتياطي.

## ملاحظات محاسبية
- قيم Dashboard تجريبية وتعتمد على الإدخالات، وليست محاسبة نهائية.
- المتأخرات تقديرية؛ يلزم فواتير مستقلة وربط دفعات جزئية بها للحصول على أرصدة صحيحة.
- CSV يفتح في Excel؛ ليس ملف XLSX أصليًا بعد.
- بيانات Excel المرفق لم تُستورد آليًا إلى نسخة العرض، لتجنب نقل بيانات حساسة أو افتراضات غير مدققة.
